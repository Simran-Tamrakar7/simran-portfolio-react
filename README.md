## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:5173/

## Build

```bash
npm run build
```

Output: `dist/`

## Project layout

- `src/App.jsx` — page shell
- `src/components/` — Hero, About, Projects, Contact, CV modal, …
- `src/data/portfolioData.js` — CV / contact / projects content
- `docs/links.md` — contact + merged-repo notes
